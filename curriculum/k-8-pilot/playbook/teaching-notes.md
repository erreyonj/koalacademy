# Teaching Notes — Standing Decisions

Decisions that shape every lesson in the pilot. If one of these changes, the syllabi and
lesson plans that depend on it need review.

## Guitar-first demonstration

The teacher's main instrument is guitar. Musical examples, demonstrations, and attention
getters lean guitar wherever possible. The classroom has a piano and a teacher keyboard; they
serve as the secondary instruments, mainly for:

- Visualizing note placement and whole/half-step patterns (the keyboard diagram made physical)
- Concepts the existing Koalacademy materials teach from a keyboard (`BMT.1`-`BMT.3`)

Where [KOALACADEMY.md](../../KOALACADEMY.md) says "demonstrate on a keyboard", assume the
pilot demonstrates on guitar first with the keyboard as the visual aid. `BMT.2` already
includes guitar demonstrations for the blues scale and modes — that pattern generalizes.

Guitar-first is about the *teacher's* demonstration instrument. The *student* hands-on
instrument is the keyboard — see [Student instrument — keyboards](#student-instrument--keyboards).

## Notebooks

Every student has a notebook. It is the default surface for the Do Now (the ticket into
class discussion — see
[routines-and-protocols.md](routines-and-protocols.md#do-now-the-ticket-in)), for journal
and listening responses, and for corrective written work. Notebooks are a standing
expectation across all bands, not a per-lesson material: assume one is on the desk every
class the same way a pencil is. Consumable notebook paper is on the acquisition list in
[classroom-setup.md](../classroom-setup.md).

- **K-2:** No student device access. Unplugged-first by design — games, movement, voice,
  found sounds, and classroom instruments, with Quaver activities run teacher-projected. Any
  student device use is an occasional extension, never a dependency.
- **3-5:** No student 1:1, but the Koala ports run a **locked hybrid** split by grade (see
  [3-5-band-differentiation.md](../resources/3-5-band-differentiation.md)). An iPad-ready 5th
  section gets a projected walkthrough then a **few-at-a-time premade-Koala rotation** while
  the rest work keyboards/instrumentation or content; 3-4 (and any not-ready 5th) stay
  **teacher-projected + instrumentation/keyboards**, falling back to half-instrument /
  half-content, with a **whole-class content/literacy floor** if instrument time breaks down.
  Thirty iPads live in the building; only the ready-5th rotation touches them in 3-5.
- **6-8:** Thirty iPads with Koala Sampler are always available, so 1:1 is the default on
  production days. Production vs. unplugged is a pedagogical choice, not a rental calendar.
  Cluster Koala-heavy work (`KSN`, `D4` hands-on, project weeks) because the work needs an
  uninterrupted You-do, not because devices have to be reserved.

See [lesson-structure.md](lesson-structure.md) for the 60-minute production-day assembly and
the post-intro concept rotation (Lesson → Review/Activity → Lab). The first Koala lab day is
gated by a file-management lesson, and continued iPad access is an earned privilege — the
full procedure and the written-learning fallback are in
[../resources/device-privilege-and-file-management.md](../resources/device-privilege-and-file-management.md).

## Student instrument — keyboards

The student hands-on instrument is the **keyboard**. Where numbers or logistics (not enough
units, not enough outlets, power-strip limits) block a keyboard for every student, run a
**keyboard station** instead: a small cluster of keyboards that groups rotate through during
the activity or lab block while the rest of the class works from the board, notebooks, or
body percussion. The station is the fallback, not a downgrade — plan the rotation into the
lesson so every student touches keys within the cycle.

### MIDI keyboards

Student keyboards do not have MIDI out, so they cannot drive Koala Sampler. Class default is
pads and the in-app Keyboard view (`KSN.2`). The teacher keyboard does have MIDI out;
students who need it schedule time at the teacher station.

## Theory pacing

The existing course front-loads theory into Unit 1 (`BMT.1`, `BMT.4`, `BMT.5` carry nearly
all notation, key signature, and meter content). In the pilot, these concepts are spaced
across the full school year and accelerated per class based on prior knowledge or
progression. The target spiral lives in [scope-and-sequence.md](../scope-and-sequence.md).

## Written work

Written work is a corrective and progress-tracking measure, not a core tenet of the course.
The full stance, including what it looks like per grade band, is in
[resources/written-work.md](../resources/written-work.md).

## Instruction pattern

Everything — games, lessons, procedures — is taught I do / We do / You do. See
[routines-and-protocols.md](routines-and-protocols.md).
