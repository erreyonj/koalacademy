# Teaching Notes — Standing Decisions

Decisions that shape every lesson in the pilot. If one of these changes, the syllabi and
lesson plans that depend on it need review.

## Guitar-first demonstration

The teacher's main instrument is guitar. Musical examples, demonstrations, and attention
getters lean guitar wherever possible. The classroom is believed to have a piano; it serves
as the secondary instrument, mainly for:

- Visualizing note placement and whole/half-step patterns (the keyboard diagram made physical)
- Concepts the existing Koalacademy materials teach from a keyboard (`BMT.1`-`BMT.3`)

Where [KOALACADEMY.md](../../KOALACADEMY.md) says "demonstrate on a keyboard", assume the
pilot demonstrates on guitar first with the keyboard as the visual aid. `BMT.2` already
includes guitar demonstrations for the blues scale and modes — that pattern generalizes.

## Devices

- **K-5:** No regular device access. K-5 is unplugged-first by design — games, movement,
  voice, found sounds, and classroom instruments. Any device use is an occasional extension,
  never a dependency.
- **6-8:** The existing Koalacademy course requires iOS devices with Koala Sampler. Access
  will be secured per-unit as needed, including renting devices for specific class days if
  necessary. Lesson pacing for 6-8 should cluster device-dependent work (`KSN`, `D4`
  hands-on, project work weeks) so rental days are efficient.

## Theory pacing

The existing course front-loads theory into Unit 1 (`BMT.1`, `BMT.4`, `BMT.5` carry nearly
all notation, key signature, and meter content). In the pilot, these concepts are spaced
across the full school year and accelerated per class based on prior knowledge or
progression. The target spiral lives in [scope-and-sequence.md](../scope-and-sequence.md).

## Written work

Written work is a corrective and progress-tracking measure, not a core tenet of the course.
The full stance, including what it looks like per grade band, is in
[resources/written-work.md](../resources/written-work.md).

## Instruction pattern

Everything — games, lessons, procedures — is taught I do / We do / You do. See
[routines-and-protocols.md](routines-and-protocols.md).
