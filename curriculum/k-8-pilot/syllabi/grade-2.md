## Course description

Second graders internalize the beat: Silent Ball arrives (passes on the downbeat only),
rhythms stretch to two bars with multiple rests, and the first real notation reading begins —
matching heard rhythms to simple written ones. Written work moves from coloring to matching
and one-measure fill-ins.

## Strand focus

| Strand | Emphasis this year |
| --- | --- |
| `BEAT` | Primary — downbeat awareness (Silent Ball); two-bar rhythm echo |
| `PITCH` | Higher/lower comparisons; simple melodies sung in tune-ish |
| `TIMBRE` | Sorting and charting found sounds by quality |
| `FORM` | Subtler A/B contrast; introduce a third (C) gesture |
| `NOTATE` | Quarter/eighth notes and rests recognized; first fill-in-the-beat pages |
| `LISTEN` | One Vanguard Song; single-word written responses begin |
| `CREATE` | Compose a one-bar body-percussion pattern |

## Games rotation

Silent Ball (downbeat, teacher counts first round), Beat Freeze (two bars, multiple rests),
Timbre Scavenger (charting), Form Detective (A/B/C). See
[playbook/games.md](../playbook/games.md) 2-3 variations.
