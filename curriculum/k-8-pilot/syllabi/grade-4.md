## Course description

Fourth graders work with vocabulary as material: Musical Taboo forces them to describe
concepts by their properties, note names land on the staff, Silent Ball moves to off-beats,
and exit tickets become a routine written artifact.

## Strand focus

| Strand | Emphasis this year |
| --- | --- |
| `BEAT` | Off-beat awareness (Silent Ball "and of _"); tempo changes mid-activity |
| `PITCH` | Note names introduced; melodic patterns sung and identified |
| `TIMBRE` | Instrument families; describing production sounds in recordings |
| `FORM` | Full-song forms; verse/chorus vocabulary alongside A/B |
| `NOTATE` | Note naming on the staff; rhythm completion in 4/4 |
| `LISTEN` | One to two Vanguard Songs; short journal entries with a weekly lens |
| `CREATE` | Compose a four-bar rhythm and teach it to a group |

## Games rotation

Musical Taboo (fewer off-limit words, long timer), Balloon War Trivia (individual, comeback
rule), Silent Ball (off-beats), Beat Freeze (off-beat rests, clapping while walking). See
[playbook/games.md](../playbook/games.md) 4-5 variations.
