## Two kinds of cousins

Some keys are related, like cousins. There are two easy pairs:

- **Relative keys** — the **same notes**, but a different **home note**.
- **Parallel keys** — the **same home note**, but a different mood.

## Relative keys

**C major** and **A minor** are **relative** keys. They use the exact same notes — no sharps or flats. The only difference is where you **start**: C for one, A for the other.

## Parallel keys

**Parallel** keys share the **same home note** but have a different mood. **C major** and **C minor** both start on **C**, but C major sounds bright and C minor sounds heavier.

Relative = same notes, different home. Parallel = same home, different mood.

3. Name the relative minor of **C major** (A minor).
