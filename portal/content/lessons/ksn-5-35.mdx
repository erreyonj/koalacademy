## A name you can find later

A pad or a project you cannot find next week might as well not exist. The most important habit in the whole app is not making sound — it is **saving**, **naming**, and putting your work **where it can be found**.

The **hamburger** (top right) is Koala's file menu. **Save**, **export**, and **settings** all live there.

## Save is not the same as turn in

Koala has two different jobs that sound alike:

| Job | What it is for |
| --- | --- |
| **Save** | Keeps your work *inside Koala* so you can open it again tomorrow |
| **Export** | Makes a file the **class folder** can see |

Saving in Koala is like keeping a drawing in your own desk. Exporting to the class folder is like handing it in. **If it is not in the class folder, it is not turned in.**

Name the file like a title, not a mess: `lastname-ksn5` or your short movie title from the Do Now — never `Recording 3`.

## What you should be able to do after this

1. Say what the hamburger menu is for.
2. Say the difference between **saving** and **exporting** (or turning in).
3. Give a file a clear name instead of `Recording`.
4. Say where your work has to go to count.

<Activate title="Name it so you can find it">

Koala day. How this runs depends on your class. This is the habit lesson — organizing and naming — so the fallback still hits the same target: **work you can find and hand in.**

**Ready 5th grade — iPad rotation.** This is the day iPads become a privilege. Before anyone opens a premade project, the class practices the file habits: open without stepping on someone else's work, **save**, give it a **clear name**, and **export it to the class folder**. Correct file use is the **exit ticket** and the way the iPad privilege is kept (see the classroom device routine).
1. *I do:* Mr. Erreyon saves, names, and exports one file to the **class folder** on the projector, and says the name out loud.
2. *We do:* The class names Save vs. Export vs. the class folder.
3. *You do:* A few students at a time save one thing, give it a clear name, and export it to the **class folder**. If it is not in the folder, the ticket is not done. Everyone else works the keyboard station or the content station. Rotate.

**3rd / 4th grade (and any 5th not on iPads) — notebook + keyboards.**
- No iPads today. Practice the same habit on paper: put your **name** and a clear **title** at the top of today's notebook work, keep it in the right section, and be able to find yesterday's page in ten seconds. Then take a turn at the **keyboard station**.

**If the keyboard block will not hold:** split the room — half organizing and naming notebook work, half at the **content station** (short excerpt or article about keeping your work + one notebook line). Swap halfway.

**If instrument time breaks down:** whole class goes to the **content/literacy station**. Read the excerpt and write two sentences: name a time you lost something because it was not put away or labeled, and what a good name or spot would have fixed. No keyboards, no iPads.

Share: two clear names on the board — a file in the folder, or a well-titled notebook page.

</Activate>
