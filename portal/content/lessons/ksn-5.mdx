  <Section name="Save and export">
    <Slide copy kicker="Save and export">

Koala uses a few different jobs.

| Job | What it is for |
| --- | --- |
| **Save** (the song / project) | Keeps your pads, sequences, and settings *inside Koala* so you can open them tomorrow |
| **Export / bounce audio** | Makes a sound file (wav / similar) other apps and the class folder can play |
| **Export settings** | The small file from `KSN.2` (queue at **SEQ END**). Not your beat. |

</Slide>
    <Slide copy kicker="Save and export">

Saving the project is not the same as putting a file on the class share. The class folder only sees what you **export** (or copy) into it.

</Slide>
    <Slide copy kicker="Save and export">

Name the file like a title, not a timestamp dump: `lastname-ksn5` or the movie title from the Do Now if it is short. No `Recording 3`.

</Slide>
    <Slide copy kicker="Save and export">

The **Files** app is how you browse what Koala saved and move it to the class share. Open **Files** from the dock → **Browse** → **On My iPad** → the **koala** folder (or **Drive** if that is where the class folder lives).

</Slide>

  <Section name="Backups">
    <Slide copy kicker="Backups">

The class folder **is** the backup we use in this room. Your iPad can be wiped. A file that only lives in Koala on one iPad is not turned in.

</Slide>
    <Slide copy kicker="Backups">

- **Rename** before you export if the name is still `Song` or `Recording`.
- **Delete** only what you made and know you do not need. Do not delete **BASICS**, class packs, or someone else's folder.
- If you overwrite a file on the share, the old one is gone. New version → new name (`-v2`) unless Mr. Erreyon says replace it.

</Slide>
