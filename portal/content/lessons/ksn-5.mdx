## Why the hamburger exists

A pad you cannot find next week is not a pad. The rest of this course — Unit 2 samples, drum kits, the final project — assumes you can **save**, **name**, and **put a file where the class can see it**.

The hamburger (top right, any tab) is Koala's file and settings menu. `KSN.1` and `KSN.2` left it alone on purpose. Today it is the lesson.

This is a **production day**. Devices out as a routine after the Do Now. We stay on SAMPLE or SEQUENCE only long enough to have something worth saving. Perform still waits.

## User folders and the Samples drawer

You already opened **^ SAMPLES** in `KSN.1`. Class files live there. Today you add **your** place inside that system.

1. Open **^ SAMPLES**.
2. Find **ADD LOCATION** / a new folder (teacher shows the exact tap on the projected iPad — iPadOS file picker wording moves).
3. Name it with **your name** or your Koalacademy handle — not `Folder`, not `aaaa`.
4. That folder is where **your** samples and exports go. **BASICS** stays BASICS. Do not dump class packs into your folder and call them yours.

A named folder is how Mr. Erreyon can tell whose work is whose when thirty iPads hit the same share.

## Importing audio

Koala can take audio from:

- Record onto a pad (`KSN.1`)
- **^ SAMPLES** → a class folder we already loaded
- Files / a share you pick with **ADD LOCATION**
- Packs under **GET MORE SAMPLES** — not required, not homework

**Splice** is still a conversation about how producers find sounds in the world. It is **not** a login for this room. If a lesson needs a file, it is already on the iPad or in the class folder.

Import one short file only if we put one in the class folder for today. Label the pad. Long files clog the machine.

## Save, export, and what the words mean

Koala uses a few different jobs. Do not mix them up.

| Job | What it is for |
| --- | --- |
| **Save** (the song / project) | Keeps your pads, sequences, and settings *inside Koala* so you can open them tomorrow |
| **Export / bounce audio** | Makes a sound file (wav / similar) other apps and the class folder can play |
| **Export settings** | The small file from `KSN.2` (queue at **SEQ END**). Not your beat. |

Saving the project is not the same as putting a file on the class share. The class folder only sees what you **export** (or copy) into it.

Name the file like a title, not a timestamp dump: `lastname-ksn5` or the movie title from the Do Now if it is short. No `Recording 3`.

## Backups, rename, delete

The class folder **is** the backup we use in this room. Your iPad can be wiped. A file that only lives in Koala on one iPad is not turned in.

- **Rename** before you export if the name is still `Song` or `Recording`.
- **Delete** only what you made and know you do not need. Do not delete **BASICS**, class packs, or someone else's folder.
- If you overwrite a file on the share, the old one is gone. New version → new name (`-v2`) unless Mr. Erreyon says replace it.
