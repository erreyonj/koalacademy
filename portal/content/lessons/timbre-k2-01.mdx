<Activate title="Timbre Scavenger">

One target word for the whole class today: **scratchy**. Plant a few clear finds before class; the rest of the room is fair game.

1. *I do:* Teacher taps two contrasting objects and names their timbres out loud — smooth vs scratchy.
2. *We do:* Class tests one shared object together and votes on the best describing word.
3. *You do:* Whole class hunts for **scratchy**. Test quiet. Bring finds back to the carpet at level 0. The class decides which ones match.

Every student (or pair) presents a matching sound. Celebrate surprising valid finds.

Full rules live in the game bank: Timbre Scavenger.

</Activate>
