# Keys.lite illustrations

`keys-lite-rh-frame-*.png` are original Koalacademy Canva drawings of a
right hand for one octave of C major. Filenames map to scale degree:

- `frame-1` — rest / C (degree 1)
- `frame-2+5` — D and G (index)
- `frame-3+6` — E and A (middle)
- `frame-4` — F after the thumb-under
- `frame-7` — B (ring)
- `frame-8` — C an octave up (pinky)

Left hand reuses the same files, CSS-flipped. Finger numbers overlay the
tips during playback; white cutouts sit on a white gutter.
