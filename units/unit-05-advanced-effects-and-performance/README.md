# Unit 5: Advanced Effects Processing and Performing with Koala Sampler

Full lesson content: [Unit 5 in KOALACADEMY.md](../../curriculum/KOALACADEMY.md#unit-5-advanced-effects-processing-and-performing-with-koala-sampler)

## Unit goals

Push Koala past pattern building. Students use effects as compositional tools, situate Koala among
other iOS production apps, then restructure their finished project into a live set and perform it.

By the end of the unit a student has a locked final project, a live recording of it, a performable
set layout, and a public performance with the analytical context behind it.
